私藏已久的实用网站推荐，每一个都超好用！

发表于2026-06-01|更新于2026-06-01|资源分享

📌 写在前面

互联网上的好工具层出不穷，但很多宝藏网站都藏在角落里。这篇文章我精挑细选了 10个实用网站，涵盖设计、开发、办公、学习四个方向，每一个都是我亲自用过觉得好用的。

建议收藏这篇，说不定哪天就用上了！

🎨 一、设计类

1. Remove.bg —— 一键抠图神器

网址：https://www.remove.bg/zh

还在用 PS 一点点抠图？Remove.bg 可以 5 秒内自动去除图片背景，完全免费，效果惊艳！

特点：

  • 上传图片自动识别主体
  • 支持人像、商品、动物等各种类型
  • 可下载高清透明背景图片

适用场景：抠人像、做产品图、制作证件照

2. Coolors —— 配色灵感库

网址：https://coolors.co/

设计师和博主必备的配色工具，按空格键就能随机生成一套 5色配色方案。

特点：

  • 一键锁定喜欢的颜色，再按空格换其他色
  • 可导出为 CSS、图片、PDF 格式
  • 支持上传图片提取配色

适用场景：网站配色、PPT 设计、海报制作

3. Iconfont —— 阿里巴巴矢量图标库

网址：https://www.iconfont.cn/

国内最好用的免费图标库，600万+ 矢量图标任你下载。

特点：

  • 可搜索中英文关键词
  • 支持 SVG、PNG、AI 多种格式
  • 可在线调整颜色和大小

适用场景：网页图标、PPT 图标、App 设计

💻 二、开发类

4. Carbon —— 生成漂亮的代码截图

网址：https://carbon.now.sh/

程序员必备！把你的代码变成 高颜值的截图，方便分享到社交平台。

特点：

  • 支持 50+ 种编程语言
  • 可自定义主题、背景色、字体
  • 一键导出 PNG/SVG

适用场景：技术文章配图、代码分享、简历展示

5. JSON.cn —— JSON 格式化工具

网址：https://www.json.cn/

在线 JSON 解析和格式化工具，界面简洁无广告。

特点：

  • 自动格式化、校验 JSON
  • 支持 JSON 转 XML/CSV
  • 深色模式护眼

适用场景：调试 API 接口、处理数据

6. Regex101 —— 正则表达式测试工具

网址：https://regex101.com/

写正则表达式必备的测试工具，实时匹配 + 详细解释。

特点：

  • 支持多种正则引擎
  • 右侧自动生成正则解释
  • 可保存常用的正则

适用场景：表单验证、文本处理、数据清洗

📝 三、办公效率类

7. TinyPNG —— 图片无损压缩

网址：https://tinypng.com/

网页加载慢？多半是图片太大。TinyPNG 可以在 不损失画质 的情况下减少 50%-70% 的图片体积。

特点：

  • 支持 PNG、JPG、WebP 格式
  • 单次最多压缩 20 张
  • 完全免费

适用场景：博客配图、网站优化、邮件附件

8. Smallpdf —— 全能 PDF 工具箱

网址：https://smallpdf.com/cn

PDF 压缩、合并、转换、编辑，一个网站全搞定。

特点：

  • 支持 PDF 转 Word、PPT、Excel
  • 免费版每天可用 2 次
  • 上传的文件 1 小时后自动删除

适用场景：处理合同、简历、电子书

9. 幕布 —— 极简大纲笔记

网址：https://mubu.com/

比 Word 轻量，比记事本强大。大纲笔记写完后，一键生成思维导图。

特点：

  • 支持多级缩进，结构清晰
  • 可导出为图片、PDF、Word
  • 多端同步（Web+App）

适用场景：写提纲、做读书笔记、会议记录

📚 四、学习类

10. Oeasy —— 免费的全能教程网站

网址：http://oeasy.org/

真正的宝藏网站！从 PS 到编程，从音乐到办公软件，全部免费！

特点：

  • 视频教程 + 文字笔记
  • 内容通俗易懂，适合零基础
  • 持续更新中

适用场景：自学设计、编程、办公软件

🎁 彩蛋：我的常用工具链

场景 工具 理由
做图 Canva 模板多，操作简单
录屏 OBS 免费开源，功能强大
写作 Typora 沉浸式 Markdown 体验
待办 Microsoft To Do 微软出品，全平台同步
翻译 DeepL 比谷歌翻译更自然

📖 总结

类别 推荐网站
设计 Remove.bg、Coolors、Iconfont
开发 Carbon、JSON.cn、Regex101
办公 TinyPNG、Smallpdf、幕布
学习 Oeasy

以上这些网站都是 免费或有限免费 的，日常使用完全足够。

💡 小建议：不需要一次性记住所有网站，把这篇收藏起来，需要的时候翻出来看看就行。

如果你也有私藏的宝藏网站，欢迎在评论区分享给大家！🌹
