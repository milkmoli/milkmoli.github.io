❓ 常见问题

Q1：脚本不生效怎么办？

  1. 确认油猴扩展已启用
  2. 检查脚本是否匹配当前网页（查看脚本的 @match 或 @include 规则）
  3. 按 F12 打开控制台，查看是否有报错信息
  4. 尝试刷新页面或重新安装脚本

Q2：可以提需求或反馈 Bug 吗？

当然可以！欢迎通过以下方式联系我：

  • GitHub Issues：链接
  • 评论区留言

Q3：脚本会收集我的数据吗？

不会。所有脚本代码开源透明，运行在本地浏览器中，不收集任何个人信息。
